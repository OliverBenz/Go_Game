# Testing


## Test Types
This is general knowledge, just adding it again.

Test Type   | What is tests | Notes
-----------------------------------
Unit        | Smalles logicical units in isolation      | Vision: synthetic board
Integration | Interaction between modules               | Vision: real images
Regression  | Test that fixed bugs are not reintroduced | 
Golden      | Output matches known "golden" results     | For vision algorithm with large test sets.
Fuzz        | Robustness to bad input                   |

So far no GUI tests, performance tests, system tests, and compatibility tests.
